# CCR Task Tracker (Notion Template)

A Notion database template for tracking Change Control Requests (CCRs) through their regulatory lifecycle — status, molecule/product tags, and key dates. This is a blank template shell (no real task data) intended as a starting point for other RA teams to duplicate and adapt.

## Use it

[**Duplicate this template →**](https://scratch-allspice-aab.notion.site/b092c90c007b407bae7a7333af875789?v=3e9941e42497816da163000cb3d2e75a)

Opening the link and clicking **Duplicate** (top right) copies the full database — properties, views, and tag categories — into your own Notion workspace. No account data or real tracker entries are included.

## Notes

- This is a template shell only — column structure and tag categories, no live CCR data.
- Adapt tag/select options to your own molecules, sponsors, or workflow stages after duplicating.

## Claude + Notion Integration

Claude can connect directly to Notion via its connector, which means it can work alongside this tracker rather than as a separate step: findings from the [`tga-regulatory-analysis`](../tga-regulatory-analysis) skill (variation classification, rationale, TGA guidance references) can be written straight into the corresponding CCR entry — updating status, adding notes, or creating follow-up tasks — instead of copying output between tools manually.
