# CMI Checklist
## Consumer Medicine Information — TGA Structural & Content Requirements

> Based on: TGA *Requirements for consumer medicine information* and the *CMI template for prescription medicines*.
> Apply this checklist when reviewing a draft or revised CMI document.

---

## Section 1 — Document Header and Identification

| # | Requirement | Assessment |
|---|---|---|
| 1.1 | Document is titled "CONSUMER MEDICINE INFORMATION" (not "Patient Information Leaflet" or similar, unless TGA has approved an alternative) | PASS / FLAG / FAIL |
| 1.2 | Brand name and INN/common name are present in the header | PASS / FLAG / FAIL |
| 1.3 | Strength and dosage form are stated | PASS / FLAG / FAIL |
| 1.4 | CMI version/date is present (footer or header) | PASS / FLAG / FAIL |
| 1.5 | "Read this leaflet carefully before taking/using this medicine" or equivalent instruction is present | PASS / FLAG / FAIL |

## Section 3 — "What [Brand Name] is used for"

| # | Requirement | Assessment |
|---|---|---|
| 3.1 | Approved indication(s) are described in plain consumer language | PASS / FLAG / FAIL |
| 3.2 | Indication description is consistent with the approved PI | PASS / FLAG / FAIL |
| 3.3 | No unapproved (off-label) uses are listed | PASS / FLAG / FAIL |
| 3.4 | If the indication has known unanswered questions, they are not overstated | PASS / FLAG / FAIL |

---

## Section 4 — "Before you take/use [Brand Name]"

| # | Requirement | Assessment |
|---|---|---|
| 4.1 | **When you must not take it** — absolute contraindications are listed in consumer-friendly language | PASS / FLAG / FAIL |
| 4.2 | Allergy/hypersensitivity contraindication is present ("Do not take if you are allergic to...") | PASS / FLAG / FAIL |
| 4.3 | **Before you start** — precautions are covered (conditions to tell your doctor about) | PASS / FLAG / FAIL |
| 4.4 | Pregnancy and breastfeeding advice is present | PASS / FLAG / FAIL |
| 4.5 | Paediatric / age-related guidance is present where relevant | PASS / FLAG / FAIL |
| 4.6 | Effects on driving/operating machinery are addressed | PASS / FLAG / FAIL |
| 4.7 | **Taking other medicines** — key drug interactions are listed in consumer-friendly language | PASS / FLAG / FAIL |
| 4.8 | If excipients of significance are present (e.g., lactose, sulphites, aspartame), consumer-appropriate warnings are present | PASS / FLAG / FAIL |

---

## Section 5 — "How to take/use [Brand Name]"

| # | Requirement | Assessment |
|---|---|---|
| 5.1 | Recommended dose and dosing regimen are stated | PASS / FLAG / FAIL |
| 5.2 | Administration instructions are clear (e.g., with food, how to swallow, not to crush/split where applicable) | PASS / FLAG / FAIL |
| 5.3 | Duration of treatment is stated where applicable | PASS / FLAG / FAIL |
| 5.4 | What to do if a dose is missed is addressed | PASS / FLAG / FAIL |
| 5.5 | What to do in case of overdose is addressed — including instruction to contact Poisons Information Centre (13 11 26) or emergency services | PASS / FLAG / FAIL |
| 5.6 | Dosage information is consistent with the approved PI | PASS / FLAG / FAIL |

## Section 6 — "While you are taking/using [Brand Name]"

| # | Requirement | Assessment |
|---|---|---|
| 6.1 | Monitoring requirements or tests the patient should be aware of are stated | PASS / FLAG / FAIL |
| 6.2 | Key warnings about activities, diet, or lifestyle changes are addressed | PASS / FLAG / FAIL |
| 6.3 | Any required safety monitoring for the patient (e.g., blood tests, BP monitoring) is described in consumer-friendly terms | PASS / FLAG / FAIL |

---

## Section 7 — "Side effects"

| # | Requirement | Assessment |
|---|---|---|
| 7.1 | Common and/or serious side effects are listed | PASS / FLAG / FAIL |
| 7.2 | Side effects are described in consumer-friendly language (not just MedDRA terms) | PASS / FLAG / FAIL |
| 7.3 | Serious side effects requiring immediate medical attention are clearly highlighted (e.g., bold, "Tell your doctor immediately if...") | PASS / FLAG / FAIL |
| 7.4 | Instruction to report side effects to a healthcare professional or sponsor is present | PASS / FLAG / FAIL |
| 7.5 | Side effects are consistent with the PI adverse effects section | PASS / FLAG / FAIL |
| 7.6 | Reference to TGA's adverse event reporting (e.g., "You can also report side effects to...") is present | PASS / FLAG / FAIL |

---

## Section 8 — "After taking/using [Brand Name]"

| # | Requirement | Assessment |
|---|---|---|
| 8.1 | Storage conditions are stated in consumer-friendly language | PASS / FLAG / FAIL |
| 8.2 | Storage conditions are consistent with the label and PI | PASS / FLAG / FAIL |

| 8.4 | Disposal instructions are present (e.g., "Return to your pharmacist for disposal" / reference to Return Unwanted Medicines scheme) | PASS / FLAG / FAIL |
| 8.5 | Instruction not to use if expiry date has passed is present | PASS / FLAG / FAIL |

| # | Requirement | Assessment |

## Section 10 — "Supplier details"

| # | Requirement | Assessment |
|---|---|---|
| 10.1 | Sponsor name is present | PASS / FLAG / FAIL |
| 10.2 | Sponsor's Australian address is present | PASS / FLAG / FAIL |
| 10.3 | Sponsor contact phone number and/or website is present | PASS / FLAG / FAIL |
| 10.4 | Sponsor details match the current ARTG registration | PASS / FLAG / FAIL |

---

## Section 11 — Readability and Language

| # | Requirement | Assessment |
|---|---|---|
| 11.1 | Language is plain English, avoiding complex medical or scientific terminology without explanation | PASS / FLAG / FAIL |
| 11.2 | Second person ("you") is used consistently | PASS / FLAG / FAIL |
| 11.3 | Reading level is appropriate for a general adult consumer audience | PASS / FLAG / FAIL |
| 11.4 | Sentences are clear and not excessively long | PASS / FLAG / FAIL |
| 11.5 | Abbreviations are explained on first use | PASS / FLAG / FAIL |

---

## Section 12 — CMI–PI Consistency

| # | Requirement | Assessment |
|---|---|---|
| 12.1 | Indications in CMI are consistent with PI indications | PASS / FLAG / FAIL |
| 12.2 | Contraindications in CMI are consistent with PI | PASS / FLAG / FAIL |
| 12.3 | Dosage information in CMI is consistent with PI dosage section | PASS / FLAG / FAIL |
| 12.4 | Side effects in CMI are consistent with PI adverse effects section | PASS / FLAG / FAIL |
| 12.5 | Storage conditions in CMI match PI and label | PASS / FLAG / FAIL |
| 12.6 | Sponsor name and address in CMI match PI and label | PASS / FLAG / FAIL |
| 12.7 | ARTG number in CMI matches PI and label | PASS / FLAG / FAIL |
| 12.8 | PI version and CMI version dates are aligned (both reflect the same approved version) | PASS / FLAG / FAIL |

## CMI Key References

- **CMI template:** *CMI template for prescription medicines* (TGA)
- **Consumer language guidance:** TGA guidelines on plain language for CMI
- **Adverse event reporting:** TGA *Report an adverse event* webpage
- **Return Unwanted Medicines:** RUM Project (www.returnmed.com.au)
- **Poisons Information Centre:** 13 11 26 (Australia-wide)
