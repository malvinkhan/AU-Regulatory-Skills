# PI Checklist
## Product Information — TGA Structural & Content Requirements

> Based on: TGA *Requirements for product information* and the *Product information template for prescription medicines* (updated October 2020).
> Apply this checklist when reviewing a draft or revised PI document.

---

## Section 1 — Document Header and Identification

| # | Requirement | Assessment |
|---|---|---|
| 1.1 | The document is titled "PRODUCT INFORMATION" | PASS / FLAG / FAIL |
| 1.2 | Brand name is present in the header | PASS / FLAG / FAIL |
| 1.3 | INN/common name and strength are present in or immediately after the header | PASS / FLAG / FAIL |
| 1.4 | The PI date (date of most recent TGA-approved revision) is present in the footer or header | PASS / FLAG / FAIL |
| 1.5 | Sponsor name is present in the document (header, footer, or Sponsor section) | PASS / FLAG / FAIL |

## Section 11 — ADVERSE EFFECTS

| # | Requirement | Assessment |
|---|---|---|
| 11.1 | Adverse effects are listed systematically (e.g., by system organ class or frequency category) | PASS / FLAG / FAIL |
