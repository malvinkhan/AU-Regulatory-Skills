## Therapeutic Goods Order No. 91 — Standard for Labels of Prescription and Related Medicines

> **Scope:** TGO 91 applies to **Schedule 4 and Schedule 8 prescription medicines**.
> Apply this checklist to all label components: primary pack carton (main label + other panels), immediate container label, and blister/strip foil where applicable.
> Section references are from TGO 91 unless otherwise noted.

---

## PART A — PRIMARY PACK (CARTON) MAIN LABEL

### A1 — Schedule Entry / Cautionary Statement

| # | Requirement | TGO 91 Reference | Assessment |
|---|---|---|---|
| A1.1 | "PRESCRIPTION ONLY MEDICINE" is present | Poisons Standard (SUSMP) Part 2, 1.3(1) | PASS / FLAG / FAIL |
| A1.2 | "KEEP OUT OF REACH OF CHILDREN" is present | SUSMP Part 2, 1.3(1) | PASS / FLAG / FAIL |
| A1.3 | Both statements appear on the label of the **primary pack** | SUSMP Part 2, 1.3(1) | PASS / FLAG / FAIL |
| A1.4 | Both statements are **more prominent** than other label text (i.e., schedule entry is the most conspicuous element) | TGO 91 s.9(2) | PASS / FLAG / FAIL |
| A1.5 | For Schedule 8: "CONTROLLED DRUG — Possession without authority illegal" appears instead of / in addition to Rx statement | SUSMP Part 2, 1.3(2) | PASS / FLAG / FAIL / N/A |

> **Note on bottles without outer carton:** If the medicine is in an immediate container only (no carton), and the container capacity is >10 mL, the cautionary statement must appear on the immediate container label.

### A8 — Space for Dispensing Label

| # | Requirement | TGO 91 Reference | Assessment |
|---|---|---|---|
| A8.1 | A space of **at least 70 mm × 30 mm** is provided on the label for the pharmacist's dispensing label | s.8(2)(a) | PASS / FLAG / FAIL |
| A8.2 | Space is on the primary pack (carton); or on the container if there is no carton | s.8(2)(a) & s.10 | PASS / FLAG / FAIL |
| A8.3 | Dispensing label space is free of mandatory information that would be obscured when a label is applied | guidance | PASS / FLAG / FAIL |
| A8.4 | Words "Place label here" or equivalent are printed in the space | guidance (best practice) | PASS / FLAG |
| A8.5 | After a dispensing label is affixed, the following remain visible: batch number, expiry, storage, product name, strength, active ingredients, dosage form, barcode, warnings, AUST R number | guidance | PASS / FLAG / FAIL |

### B6 — Declaration of Substances (Schedule 1 Excipients)

| # | Requirement | TGO 91 Reference | Assessment |
|---|---|---|---|
| B6.1 | All Schedule 1 substances present in the formulation are declared — either on the label, OR via a statement directing the consumer to the CMI | s.8(1)(j)(i–iv) | PASS / FLAG / FAIL |
| B6.2 | If declared on the label: declaration uses required wording (e.g., "Contains lactose", "Contains aspartame", "Contains sulphites") | Schedule 1 to TGO 91 | PASS / FLAG / FAIL |
| B6.3 | If directing to CMI: a statement **specifically alerting consumers to the presence** of declarable substances appears on the label (not just a generic "see CMI" statement) | s.8(1)(j) & guidance | PASS / FLAG / FAIL |
| B6.4 | For injections: **all excipients** present in the formulation are declared on the label | s.10(2)–(5) | PASS / FLAG / FAIL / N/A |
| B6.5 | For ophthalmic/nasal/topical medicines: antimicrobial preservative is declared on the container label and primary pack | s.10(9) / s.10(11) | PASS / FLAG / FAIL / N/A |

| Substance | Required statement |
|---|---|

| Ethanol (>0.5% v/v) | Alcohol content statement |
| Azo dyes (e.g., tartrazine, sunset yellow) | "Contains [dye name]" |
| Benzalkonium chloride | "Contains benzalkonium chloride" |
| Peanut oil / soya bean oil | Allergy warning |

## PART C — CONTAINER LABEL (IMMEDIATE CONTAINER)

### C1 — Reduced Requirements for Containers Supplied in a Carton

|---|---|---|---|
| C1.1 | Medicine name is present on the container label | s.9(1)(a) | PASS / FLAG / FAIL |
| C1.2 | Active ingredient name(s) are present on the container label | s.9(1)(b) | PASS / FLAG / FAIL |
| C1.3 | Active ingredient quantity/quantities are present | s.9(1)(c) | PASS / FLAG / FAIL |
| C1.4 | Batch number is present | s.8(1)(f) | PASS / FLAG / FAIL |
| C1.5 | Expiry date is present | s.8(1)(g) | PASS / FLAG / FAIL |

## PART D — BLISTER / STRIP FOIL LABEL

### D1 — Blister/Strip Requirements (Supplied in a Primary Pack)

Applies where the medicine is supplied in a blister or strip pack with an outer carton. Required information must repeat at a minimum frequency.

| # | Requirement | TGO 91 Reference | Assessment |
|---|---|---|---|
| D1.1 | **Expiry date and expiry prefix** are present on the blister foil | s.10(14)(a)(viii) | PASS / FLAG / FAIL |
| D1.2 | **Batch number and batch prefix** are present on the blister foil | s.10(14)(a)(vii) | PASS / FLAG / FAIL |
| D1.3 | **Name AND quantity of active ingredient(s)** are present on the blister foil (for products with 1–3 active ingredients) | s.10(14)(a)(v)(vi) & s.11(2)(a) | PASS / FLAG / FAIL |
| D1.4 | For products with **4 or more** active ingredients: name of the medicine only is required to repeat on the foil (not ingredient details) | s.10(14)(c)(i) | PASS / FLAG / FAIL / N/A |
| D1.5 | **Name of the medicine AND active ingredient(s)** repeat **at least once per every two dosage units** on the foil (for perforated blisters where individual units can be readily detached) | s.10(14)(c)(i) | PASS / FLAG / FAIL |
| D1.6 | **Name or registered trademark of the sponsor/distributor** is present on the blister foil | s.10(14)(a)(ix) | PASS / FLAG / FAIL |
