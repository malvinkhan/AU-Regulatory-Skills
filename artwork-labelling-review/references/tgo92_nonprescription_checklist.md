# TGO 92 — Non-Prescription Medicine Label Checklist
## Therapeutic Goods Order No. 92 — Standard for Labels of Non-Prescription Medicines

> **Scope:** TGO 92 applies to **Schedule 2, Schedule 3 (pharmacist-only), and unscheduled medicines** (OTC, complementary, listed). It does NOT apply to prescription medicines (those are covered by TGO 91).
> Section references are from TGO 92 unless otherwise noted.

---

## PART B — CRITICAL HEALTH INFORMATION (CHI) — REGISTERED NON-PRESCRIPTION MEDICINES

> **CHI requirements apply to most registered non-prescription medicines** (generally Schedule 2, Schedule 3, and some unscheduled registered medicines). Listed (AUST L) medicines are NOT required to use tabulated CHI but are encouraged to do so.
> See s.8(3) for specific exemptions.

### B1 — CHI Table — Structure and Mandatory Format

| # | Requirement | TGO 92 Reference | Assessment |
|---|---|---|---|
| B1.1 | CHI is displayed in a **tabulated format** (a clearly defined panel/table) | s.8(2) | PASS / FLAG / FAIL |
| B1.2 | CHI table has a **white or other strongly contrasting background** | s.8(2) | PASS / FLAG / FAIL |
| B1.3 | All CHI text and punctuation are in **only one colour** | s.8(2) | PASS / FLAG / FAIL |
| B1.4 | CHI text is **black or another dark colour** | s.8(2) | PASS / FLAG / FAIL |
| B1.5 | CHI table does **not** contain logos, graphics, or marketing claims (e.g., "free from" statements) | s.8(2) | PASS / FLAG / FAIL |
| B1.6 | No bolding, different colours, or fonts are used to highlight CHI text (except for headings/subheadings, or where mandatory) | s.8(2) | PASS / FLAG / FAIL |

### B2 — CHI Headings — Mandatory Order

The following headings must appear in this order in the CHI table. Exact wording can vary but meaning must be equivalent:

| # | Required Heading (or equivalent wording) | TGO 92 Reference | Present? | In Order? | Assessment |
|---|---|---|---|---|---|
| B2.1 | **Active ingredient(s) and quantity** (or "Active Ingredient", "What's in it") | s.8(2)(b) | Y/N | Y/N | PASS / FLAG / FAIL |
| B2.2 | **Indications** (or "Uses", "What this medicine is used for") | s.8(2)(b) | Y/N | Y/N | PASS / FLAG / FAIL |
| B2.3 | **Warnings** (or "Warnings and precautions", "Do not use if") | s.8(2)(b) | Y/N | Y/N | PASS / FLAG / FAIL |
| B2.4 | **Directions for use** (or "How to use", "Dosage") | s.8(2)(b) | Y/N | Y/N | PASS / FLAG / FAIL |
| B2.5 | **Other information** (OPTIONAL — covers storage, tamper evidence, sponsor contact, full ingredient list) | s.8(2)(e) | Y/N | Y/N | PASS / FLAG / N/A |

### B3 — CHI Content — Warnings Section

| # | Requirement | TGO 92 Reference | Assessment |
|---|---|---|---|
| B3.1 | All **mandatory RASML warnings** that apply to this medicine are present in the Warnings section | RASML / MASS | PASS / FLAG / FAIL |
| B3.2 | All **Schedule 1 declarable substances** are listed under Warnings (even if also in an ingredients list elsewhere in the table) | Schedule 1 & s.8(2) | PASS / FLAG / FAIL |
| B3.3 | Serious warnings requiring immediate action are clearly highlighted (e.g., "Do not use if...", "Stop use and see a doctor if...") | RASML | PASS / FLAG / FAIL |
| B3.4 | Poisons Information Centre number (13 11 26) is present where relevant (e.g., overdose warnings for paracetamol, ibuprofen) | RASML | PASS / FLAG / FAIL / N/A |

### B4 — CHI Content — Directions for Use Section

| # | Requirement | TGO 92 Reference | Assessment |
|---|---|---|---|
| B4.1 | Dosing regimen for each approved indication is stated | s.8(2)(b) | PASS / FLAG / FAIL |
| B4.2 | Dose is expressed in **metric units** (mL, g, number of tablets) — NOT in culinary spoonsful | s.8(2) & s.11 | PASS / FLAG / FAIL |
| B4.3 | Maximum daily dose is stated | RASML / guidance | PASS / FLAG / FAIL |
| B4.4 | Dosage is given for each relevant age group (adults; children by age; "for adults only" if applicable) | s.8(2)(b) | PASS / FLAG / FAIL |
| B4.5 | Duration of treatment / maximum duration is stated where required by RASML | RASML | PASS / FLAG / FAIL |
| B4.6 | Missed dose guidance is present where relevant | guidance | PASS / FLAG |
| B4.7 | If directions are too long to fit: a package insert is included AND the CHI table references it ("Please refer to package insert for instructions") | s.8 | PASS / FLAG / FAIL / N/A |

- **RASML:** Required Advisory Statements for Medicine Labels (schedules to MASS — Medicines Advisory Statements Specification)
- **Declarable excipients:** Schedule 1 to TGO 92
- **CHI requirements:** TGO 92 s.8(2)
- **Listed medicine exemptions:** TGO 92 s.8(3)
- **Poisons Information Centre (Australia):** 13 11 26
