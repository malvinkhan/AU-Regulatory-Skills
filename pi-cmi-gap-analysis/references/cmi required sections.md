# TGA Required CMI Sections — Checklist Reference

> Based on: *Consumer medicine information (CMI)* guidance (TGA, current version)  
> Apply this checklist to any Consumer Medicine Information (CMI) for a prescription medicine registered on the ARTG.

---

## Required Headings and Key Content

### 1. Medicine Name
- Brand name (if applicable) and INN/AAN
- Strength and dosage form
- Sponsor name

### 2. What [Medicine Name] Is Used For
- Plain-English description of the approved indication(s)
- Must reflect (not extend beyond) the approved indication from the PI
- Language accessible to a general consumer

### 3. Before You Take [Medicine Name]
#### 3.1 When You Must Not Take It
- Contraindications from PI translated to plain English
- Hypersensitivity
- Absolute contraindications

#### 3.2 Before You Start Taking It / Precautions
- Key warnings and precautions from PI in consumer-appropriate language
- Use in pregnancy and breastfeeding (consistent with PI pregnancy category and guidance)
- Driving/operating machinery warning (if applicable)
- Other special precautions relevant to consumer

#### 3.3 Taking Other Medicines
- Key drug interactions from PI in consumer-appropriate language
- Food and alcohol interactions
- Instruction to tell pharmacist/doctor about all medicines being taken

### 4. How to Take [Medicine Name]
- Recommended dose and frequency in plain language
- Route of administration
- What to do if a dose is missed
- What to do in case of overdose (including reference to Poisons Information Centre: 13 11 26)
- Duration of treatment if specified

### 5. While You Are Taking [Medicine Name]
- Monitoring requirements
- Lifestyle advice (diet, activity, alcohol)
- When to contact the doctor
- Any other relevant on-treatment information

### 6. Side Effects
- Most important/common side effects in consumer language
- Serious adverse effects requiring urgent medical attention
- Must be consistent with PI Adverse Effects section (not contradictory; may be simplified but not omit serious events)
- Instruction to report side effects to doctor/pharmacist

### 7. After Using [Medicine Name] — Storage
- Storage conditions in plain language (consistent with PI and label)
- Shelf life information
- Post-opening storage (if applicable)
- Disposal instructions (e.g., return to pharmacist)
- Keep out of reach of children

### 8. Product Description
- Physical description of the dosage form (colour, shape, markings, size)
- Available pack sizes and strengths

### 9. Sponsor Information
- Australian sponsor name, address, and phone number
- Must match the ARTG record

### 10. Date of Preparation / Last Revision
- Date CMI was last revised
- Must be updated whenever the CMI is amended

---

## Key Content Rules for CMI

| Rule | Detail |
|---|---|
| Plain language | All information must be understandable to a consumer without medical training |
| No extension of indication | CMI cannot state uses not approved in the ARTG/PI |
| Consistency with PI | Adverse effects, contraindications, dosage, storage must match the PI |
| Poisons Information Centre | Must include 13 11 26 (Australian number) in the overdose section |
| Pregnancy / breastfeeding | Must align with PI; use plain language |
| Sponsor details | Name and address must match current ARTG record |

---

## Common CMI Quality Issues

| Issue Type | Description |
|---|---|
| Outdated indication | Indication in CMI not updated following PI amendment |
| Missing side effects | Serious adverse effects listed in PI absent from CMI |
| Inconsistent dosage | CMI dosage differs from PI dosage (e.g., older dosing retained) |
| Missing Poisons Info Centre number | 13 11 26 absent from overdose section |
| Sponsor details mismatch | Sponsor name or address not current |
| Language too technical | Medical terminology not translated for consumer audience |
| Inconsistent storage | Storage conditions differ between CMI, PI, and label |
| Missing date of revision | Date absent or clearly outdated |
| No "keep out of reach of children" | Required statement absent from storage section |

---

## PI ↔ CMI Consistency Requirements

The following sections must be consistent between PI and CMI:

| PI Section | Corresponding CMI Section |
|---|---|
| Indications | What it is used for |
| Contraindications | When you must not take it |
| Precautions (pregnancy, lactation) | Before you start taking it |
| Interactions | Taking other medicines |
| Dosage and Administration | How to take it |
| Overdosage | How to take it (overdose subsection) |
| Adverse Effects | Side effects |
| Presentation and Storage | Storage + Product description |
| Sponsor Details | Sponsor information |
