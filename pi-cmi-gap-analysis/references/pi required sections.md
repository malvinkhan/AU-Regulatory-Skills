# TGA Required PI Sections — Checklist Reference

> Based on: *Australian product information — Guidance document* (TGA, current version)  
> Apply this checklist to any Product Information (PI) for a prescription medicine registered on the ARTG.

---

## Required Headings and Key Content

### 1. NAME OF THE MEDICINE
- INN (International Nonproprietary Name) or Australian Approved Name (AAN)
- Consistent with ARTG entry

### 2. DESCRIPTION
- Physical and chemical description of the active ingredient(s)
- CAS number (recommended)
- Structural formula (recommended)
- Molecular formula and molecular weight

### 3. PHARMACOLOGY
#### 3.1 Mechanism of Action
- Clear statement of pharmacological mechanism
- Must reflect current scientific understanding

#### 3.2 Pharmacodynamics
- Pharmacodynamic effects relevant to clinical use
- Dose-response relationship where established

#### 3.3 Pharmacokinetics
All of the following should be addressed (or noted as not applicable):
- Absorption
- Distribution (volume of distribution, protein binding)
- Metabolism (pathways, enzymes involved e.g. CYP)
- Excretion (route, elimination half-life)
- Special populations (renal impairment, hepatic impairment, elderly, paediatric, sex differences)
- Drug interaction pharmacokinetics (if clinically significant)

### 4. CLINICAL TRIALS
- Summary of key clinical trials supporting each indication
- Study design, patient population, primary endpoints, key results
- Reference to comparative studies (versus placebo and/or active comparator) where available

### 5. INDICATIONS
- Clear statement of approved therapeutic indication(s)
- Must match ARTG record exactly

### 6. CONTRAINDICATIONS
- Absolute contraindications
- Hypersensitivity to the active or excipients

### 7. PRECAUTIONS
Subsections typically include:
- Carcinogenicity (if data available)
- Genotoxicity (if data available)
- Impairment of fertility (if data available)
- Use in pregnancy (specify Category: A / B1 / B2 / B3 / C / D / X)
- Use in lactation / breastfeeding
- Paediatric use
- Geriatric use (elderly)
- Effects on ability to drive and use machines
- Any other clinically relevant special warnings

### 8. INTERACTIONS WITH OTHER MEDICINES
- Pharmacokinetic interactions (absorption, metabolism, distribution, excretion)
- Pharmacodynamic interactions (additive, synergistic, antagonistic effects)
- Interactions with food, alcohol, or other substances
- Interactions affecting laboratory tests (if relevant)
- Table format recommended for multiple interactions

### 9. ADVERSE EFFECTS
- System-organ class (SOC) format recommended (MedDRA preferred)
- Frequency categories used consistently:
  - Very common (≥1/10)
  - Common (≥1/100, <1/10)
  - Uncommon (≥1/1000, <1/100)
  - Rare (≥1/10,000, <1/1000)
  - Very rare (<1/10,000)
  - Not known (cannot be estimated from available data)
- Post-marketing adverse events (if available)

### 10. DOSAGE AND ADMINISTRATION
- Recommended dose and frequency for each approved indication
- Route of administration
- Special dosing populations:
  - Renal impairment (dose adjustments)
  - Hepatic impairment (dose adjustments)
  - Elderly
  - Paediatric (if applicable)
- Duration of treatment (if specified)
- Instructions for preparation / administration (e.g., injection reconstitution, crushing, splitting)
- Missed dose advice (if relevant)

### 11. OVERDOSAGE
- Signs and symptoms of overdose
- Emergency management / treatment
- Specific antidote (if applicable)
- Reference to Poisons Information Centre

### 12. PRESENTATION AND STORAGE
- Dosage form(s) and strength(s) listed
- Container type
- Pack size(s)
- Storage conditions (temperature, light, humidity)
- Storage after opening / reconstitution (if applicable)
- Shelf life
- AUST R / AUST L number(s)

### 13. SPONSOR DETAILS
- Name and address of the Australian sponsor
- Must match the ARTG record

### 14. DATE OF MOST RECENT AMENDMENT
- Date of last approved update
- Format: [day] [Month] [YYYY] or [Month] [YYYY]

## Common PI Quality Issues

| Issue Type | Description |
|---|---|
| Outdated information | Clinical sections not updated to reflect current approved labelling |
| Missing population subgroup | Renal/hepatic impairment dose adjustments absent |
| Inconsistency with ARTG | Indication wording differs from ARTG-approved indication |
| Obsolete adverse events section | Pre-MedDRA format or missing frequency categorisation |
| Missing excipient warnings | Excipients with known effects not listed in Precautions |
| Grammar/spelling errors | Typographical errors that may create ambiguity |
| Outdated sponsor address | Address doesn't match current ARTG record |
| Missing date of amendment | Section 14 absent or clearly out of date |

---

## Cross-Document Consistency Requirements

The PI must be consistent with:
- **CMI** — Adverse effects, indications, dosage, storage must align (patient-appropriate language, same information)
- **ARTG record** — Indications, brand name, sponsor, AUST R number
- **Label artwork** — Indications, dosage form, strength, storage, sponsor details, AUST R
- **Reference/innovator PI** — For generics: no unapproved claims or deletions of safety information vs the reference PI
