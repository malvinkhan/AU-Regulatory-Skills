- Publisher: Therapeutic Goods Administration

- Source (download here): https://www.tga.gov.au/resources/guidance/variations-prescription-medicines-excluding-variations-requiring-evaluation-clinical-or-bioequivalence-data-chemical-entities

## Why it isn't included in this repo

The document is Commonwealth copyright material. The TGA's copyright notice permits personal or internal organisational use but does not extend to public redistribution, so it is intentionally excluded from this public repo.

## Setup

1. Download the PDF from the TGA link above.
2. Place it in this folder as `tga_variation_types_appendix1.pdf` (this filename is gitignored, so it will stay local and won't be committed).
3. Check the TGA site periodically for newer versions — this skill was written against V3.1 (January 2020); update the reference and the `SKILL.md` version note if a newer version is published.
